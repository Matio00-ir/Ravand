# راهنمای انتشار ریلز روند

## فایل‌ها (پوشه‌ی `out/`)
| فایل | قلاب (۲ ثانیه‌ی اول) | مخاطب |
|---|---|---|
| `ravand-reel-A.mp4` | «کسب‌وکارت داره بی‌صدا پول از دست می‌ده» + شمارنده‌ی زیان | همه‌ی مدیران — **نسخه‌ی اصلی** (پایانش به ابتدا وصل می‌شود و لوپ می‌خورد) |
| `ravand-reel-B.mp4` | «اگه هنوز موجودی انبارت رو با اکسل حساب می‌کنی…» + اکسلِ آشفته | تولیدی، پخش، فروشگاه |
| `ravand-reel-C.mp4` | «اگه همین الان ازت بپرسم امروز چقدر سود کردی…» | مدیران ارشد و صاحبان کسب‌وکار |
| `ravand-reel-cover.png` | کاور ریلز (در گرید پروفایل هم درست دیده می‌شود) | — |

## کپشن (کپی کنید)
```
کسب‌وکارت داره بی‌صدا پول از دست می‌ده 👇

اگه این ۳ تا نشونه رو داری:
۱. برای فهمیدن موجودی انبار باید به یکی زنگ بزنی
۲. آخر ماه چند روز طول می‌کشه تا بفهمی سود کردی یا ضرر
۳. گزارش فروش و حسابداری هیچ‌وقت یکی نیستن

مشکل از تیمت نیست؛ اطلاعاتت تیکه‌تیکه‌ست.
روند فروش، انبار، مالی و مشتری‌ها رو روی یه صفحه جمع می‌کنه — لحظه‌ای.

🔸 کلمه‌ی «دمو» رو کامنت کن تا لینک دسترسی رایگان ۱۴ روزه رو دایرکت بگیری.

#مدیریت_کسب_و_کار #نرم_افزار_حسابداری #انبارداری #ERP #کارآفرینی #مدیریت_مالی #کسب_و_کار #روند
```

## کامنت پین‌شده (بلافاصله بعد از انتشار، از صفحه‌ی خود روند)
```
«دمو» رو همین‌جا کامنت کن ⬇️ لینک رو دایرکت می‌فرستیم.
کدوم یکی از این ۳ نشونه برای شما آشناتره؟ ۱، ۲ یا ۳؟
```
سؤال دوم کامنت می‌گیرد و کامنت یکی از قوی‌ترین سیگنال‌ها برای الگوریتم است.

## چطور منتشر کنید
1. **نسخه‌ی A را به‌عنوان ریلز اصلی** منتشر کنید و `ravand-reel-cover.png` را کاور بگذارید.
2. **B و C را با قابلیت Trial Reels اینستاگرام** منتشر کنید (هنگام انتشار گزینه‌ی Trial را روشن کنید). این‌ها اول فقط به غیردنبال‌کننده‌ها نشان داده می‌شوند. بعد از ۲۴ تا ۷۲ ساعت هر کدام بازدید و «نرخ تماشا» بهتری داشت، برای همه منتشرش کنید.
3. **صدا:** ویدیو صدای گوینده و موسیقی خودش را دارد. اگر خواستید ترند باشد، از داخل اینستاگرام یک موسیقی ترند اضافه کنید و صدای آن را روی ۵ تا ۱۰٪ بگذارید، طوری که صدای گوینده غالب بماند.
4. **جواب همه‌ی کامنت‌ها را در یک ساعت اول بدهید**، و «دمو»ها را فوراً دایرکت کنید (لینک: صفحه‌ی `/demo` سایت). اگر حجم بالا رفت، ابزار پاسخ خودکار دایرکت مثل ManyChat این کار را خودکار می‌کند.
5. **ساعت انتشار:** عصر روزهای کاری (حدود ۱۸ تا ۲۱) که مدیرها گوشی دستشان است. بهترین ساعت را از بخش Insights حساب خودتان پیدا کنید.
6. **استوری:** همان روز ریلز را در استوری با استیکر نظرسنجی بگذارید: «کدوم نشونه رو داری؟ ۱ / ۲ / ۳».

## بعد از انتشار — چه چیزی را نگاه کنید
- **نرخ تماشای ۳ ثانیه‌ی اول:** اگر پایین است، مشکل از قلاب است و باید نسخه‌ی دیگر را امتحان کنید.
- **میانگین زمان تماشا:** اگر مردم وسط ویدیو می‌روند، باید سرعت را بیشتر کنیم یا نشانه‌ها را کوتاه‌تر.
- **تعداد کامنت «دمو»:** معیار اصلی فروش.
- **ذخیره و اشتراک‌گذاری:** یعنی محتوا ارزش داشته است.

## ساختن نسخه‌های جدید
```
python audio/make_voice.py     # گوینده + زمان‌بندی کلمه‌به‌کلمه (متن‌ها بالای همین فایل)
python audio/make_mix.py       # موسیقی و افکت‌ها
npx remotion studio            # پیش‌نمایش و ویرایش زنده در مرورگر
npx remotion render Reel-A out/ravand-reel-A.mp4
```
